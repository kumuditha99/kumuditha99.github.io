Airport security system, Bandaranaike International Airport

SkyPass is the security access control and permit platform for Bandaranaike International Airport, Sri Lanka’s main international gateway. It runs in an airgapped on-premises data centre with no internet access, and it has to keep working through hardware and network failures. I designed the infrastructure, built it, and carried it into operation.

My role

  • Architecture ownerDesigned the complete high-availability architecture: dual virtual-IP failover with Keepalived, cluster topology, architecture diagrams and a 4-week phased build plan.
  • Database high availabilityBuilt Patroni-managed PostgreSQL and TimescaleDB clusters with etcd consensus, HAProxy routing and PgBouncer pooling, and removed a quorum single point of failure by adding a dedicated witness node.
  • Airgapped deliverySet up a private Harbor registry as the only image source and designed a zero-downtime release process with no internet: build, offline transfer, registry push and rolling recreate.
  • Platform integrationDeployed the airport security system across a redundant node pair and integrated it end to end with the core permit platform.
  • Proving resilienceValidated failover with JMeter load tests during live virtual-IP switchover, and analysed connection-pool behaviour under failover.
  • Hardware and backupsProvisioned a bare-metal Lenovo ThinkSystem server with Windows Server 2025 and Hyper-V for the quorum witness and portal VMs, and designed NAS backups with SFTP-only access.
  • SecurityFound and escalated risks such as hardcoded IPs in compiled frontend bundles and plaintext credentials in environment files, and refactored configuration to use virtual IPs.
  • Stakeholder liaisonTechnical contact for the airport’s network and security teams. Wrote the prioritised infrastructure requirements (IP reservations, DNS, NTP, internal CA, wildcard TLS, firewall policy) and traced blocked SSL inspection to a Fortinet licensing fault.

OrchiZen: award-winning smart farming with computer vision

OrchiZen is a hybrid smart farming system for orchid plantations. It automates the growing environment from live sensor data and gives growers a phone-based way to identify species and check plant health with computer vision. It won SLASSCOM’s 2025 Best Innovative Product award and was published at the IEEE 12th CACIS conference in Malaysia.

What I built

  • IoT automationA sensor and actuator network that controls irrigation, UV treatment and lighting from live readings.
  • Computer visionA YOLOv5 model for plant species and health recognition.
  • Model in the productInference served through Python (Flask) and Java Spring Boot APIs to a React Native mobile app.
  • Cloud deploymentAll services containerised with Docker and deployed on AWS, turning a research model into a usable field tool.

Secure cloud delivery for Coding Legends’ production platforms

I own how the company’s client platforms are built, shipped, secured and kept running on AWS, including the airport permit platform’s cloud environments, a KYC verification API, a blockchain wallet backend, and marketplace and property platforms. Each project gets a delivery setup designed for its own needs, team and risk profile, and I’m the person on call when production needs answers.

My role

  • CI/CD design per projectDesigned and maintain pipelines on Bitbucket Pipelines and GitHub Actions with images in Amazon ECR or GHCR, choosing the build, test, migration and release flow that fits each service.
  • Secured deploymentsEvery service behind Nginx with auto-renewing TLS, least-privilege IAM, secrets kept out of images and repositories, and hardened PostgreSQL authentication.
  • Environment architectureSeparate staging and production environments on EC2 with stable addressing, branch-based releases and consistent configuration across environments.
  • Data and storageRun PostgreSQL and TimescaleDB, Redis and MinIO object storage in production, including multi-tenant data operations, seeding and recovery. Set up S3 and CloudFront for web assets.
  • ObservabilityIntroduced Grafana, Prometheus and Loki with node and PostgreSQL exporters, giving the team real dashboards and logs for every environment.
  • Incident leadershipLed root-cause analysis of production outages, from database authentication rules and a scram-sha-256 migration to environment drift and DDL lock deadlocks, and delivered permanent fixes.
  • Build performanceReworked build pipelines and Docker images to cut build times significantly and remove heavy work from production servers.
  • Platform evolutionLed domain, DNS and TLS migrations for APIs, object storage and email, and planned the move to Kubernetes on Amazon EKS with Kustomize and autoscaling.
